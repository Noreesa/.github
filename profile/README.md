# Noreesa

### Intelligent Supply Chain Software

**From demand to delivery.**

Noreesa is building an integrated software platform that helps wholesalers and supply-chain teams turn operational data into better decisions — from demand forecasting and inventory optimisation to purchasing, warehouse operations and AI-assisted insights.

</div>

---

## What we're building

Noreesa brings planning, intelligence and operations together in one modular platform.

| Product | Focus |
| --- | --- |
| **Noreesa Forecast** | Demand forecasting, model selection, forecast accuracy and planning |
| **Noreesa Inventory** | Inventory optimisation, stock-risk detection and replenishment intelligence |
| **Noreesa Purchase** | Smarter purchasing decisions and purchase-order recommendations |
| **Noreesa WMS** | Warehouse operations from receiving and inventory to picking and shipping |
| **Noreesa Insights** | Financial and commercial intelligence, opportunities and measurable business value |
| **Noreesa AI** | AI-assisted analysis and explainable supply-chain decision support |
| **Noreesa Connect** | ERP, database, API, file and local-system integrations |

## One platform, modular by design

Our goal is a platform where customers can start with the capabilities they need and expand over time.

```text
ERP / WMS / Files / APIs
          │
          ▼
   Noreesa Connect
          │
          ▼
┌───────────────────────────────┐
│        Noreesa Platform       │
├───────────┬───────────────────┤
│ Forecast  │ Inventory         │
│ Purchase  │ Insights          │
│ AI        │ WMS               │
└───────────┴───────────────────┘
          │
          ▼
  Better decisions & actions
```

The platform is being designed around secure multi-tenant SaaS architecture, tenant isolation, auditable workflows, integration with customer data sources, and measurable operational and financial outcomes.

## Our direction

We believe supply-chain software should do more than display dashboards. It should help teams understand **what is likely to happen, what action to take, and what that action is worth**.

That means connecting forecasting with inventory, purchasing and warehouse execution — while keeping recommendations explainable and business value measurable.

## Currently in development

Noreesa is under active development. Current work includes the forecasting and supply-chain intelligence platform, production SaaS infrastructure, customer data integration, automated mapping, value measurement and a modular WMS.

Public repositories, documentation and product information will be added as components become ready for external use.
